<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust crate `corvin-chess-core` for Corvin. Intended surfaces: legal move generation, FEN load and store, SAN/UCI/PGN helpers, repetition and fifty-move helpers, and a perft suite with documented expected node counts. WASM and TypeScript bindings are planned for [web](https://github.com/corvin-chess/web) and consumers such as [server](https://github.com/corvin-chess/server) and [engine](https://github.com/corvin-chess/engine). This library is a leaf dependency with no chess-engine search. No crate source is in this repository yet.
